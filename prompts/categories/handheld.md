# Gabarit catégorie : handheld

Objet tenu en main | Axe principal, corps, fixation, embout. Taille souvent 0.5 à 4 studs. Formes fines mais jamais inférieures à 0.2 stud. Exemples : poignée arrondie, crayon, outil.

Règles : la description d'un objet spécifique est fournie par le brief, pas par du code JavaScript. Les exemples non validés par un humain sont exclus du few-shot. Sortie JSON contrôlée par le schéma. Exemple abstrait : un composant principal + attaches pertinentes, en proportions relatives à sizeStuds.
